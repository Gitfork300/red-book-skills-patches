# 01 · 第 7 步「已知问题复盘与登记」细则

> 主入口：[`../SKILL.md`](../SKILL.md) 第二节第 7 步。本文件是它的展开。
> 教训：事故**只记不闭环**等于没记（B-053 类问题会长期挂着）。收尾是唯一固定的盘点窗口，必须占用。

## 1. 盘点（脚本兜底，防漏）

```powershell
..\.venv\Scripts\python.exe helpers\bug_ledger.py --root <工作区> [--json]
```

- 输出**未闭环**条目（`未修/待查/登记/待观察`）数量与编号；退出码 0 = 已列出，2 = 台账缺失（须先建）。
- 同编号多段（登记段 + 解除段）会**聚合**：任一段含「已修/已闭环」即算该编号闭环。
- 脚本**只读**，不改写台账；回写由执行者手工完成（见第 4 点）。
- 控制台中文乱码时改用 Bash 或先 `chcp 65001`（PowerShell 5.1 代码页问题）。

## 2. 修（上限 2 项，每题 ≤2 分钟；加急模式跳过）

- 版本/登记漂移类 → 改完跑 `tools/check_patch_versions.py`
- 文档分层超限类 → 改完跑 `tools/check_doc_layers.py`
- **改完必须复跑对应校验脚本**，绿了才算闭环，否则回退为「未修」。

## 3. 登记（新发现的问题必须落台账）

- 编号 `B-0NN` + 日期 + 一句话现象 + 影响 + 后续修复方向；**不现场深挖根因**。
- 同步写进 `_NEXT_NNNN.md`（次日首要事项）与当日 memory 日志。

## 4. 闭环回写

本轮修掉的问题，在台账该条目标题加「**已修**」并在末尾写「修复于 YYYY-MM-DD」，
**不要删条目**（保留事故史）。

## 5. 回报

收尾总结里必须带一句「未闭环事故 N 条：B-0xx…；本轮新增/闭环各 X/Y 条」。
