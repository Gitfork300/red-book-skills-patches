# writing-facts-only

> Patch：用户偏好——公开发布的内容只陈述事实，不加评论、不提战略建议。
> 适用范围：所有"以账号身份公开"的图文 / 视频 / 评论。

## 加载方式

主 skill 顶部 `Loaded patches` 段会引用本 patch。本 patch 独立可加载。

## 写作规则

### 允许

- 已核实的客观事实（时间、地点、人物、动作、数据）
- 来自官方信源的直接引述
- 标注来源（"据 XX"、"XX 公布"、"据 XX 报道"）
- 中性陈述的语气（"今日 X 将召开"而非"令人期待的 X 即将开幕"）

### 不允许

- 价值判断（"好/坏/快/慢/令人失望"）
- 评价性形容词（"震撼"、"惊艳"、"诚意满满"、"豆腐渣"）
- 建议（"建议增设"、"应当改进"、"值得 X 学习"）
- 抒情收尾（"让我们一起期待"、"X 的明天会更好"）
- 互动引导话术（"你怎么看？""评论区聊聊"）
- 反问句（除非引用）
- 标题判断词（"却"、"但"、"竟"、"竟致"等带情绪的字）

### 硬约束

#### 1. 事实核查

- 任何量化数据（时间、价格、人数、距离、占比）必须双源核实。
- 时效性内容（天气、政策、调图、票价、营业时间）必须查 7 日内的信源；不查不能用。
- 互相矛盾的信源并列展示，不替读者裁决。
- 查不到 → 写"未查到公开数据"，不编。

#### 2. 应急/灾害事件双重禁令

正在生效的真实应急事件（台风、暴雨、地震、火灾、传染病、恐怖事件等）：

- ❌ 任何 AI 生成的"灾情实拍"画面
- ❌ 任何 AI 生成的"现场感"渲染
- ✅ 抽象示意 / 信息图（无具体地理要素）
- ✅ 官方通报的事实摘录
- 末尾必须标注来源与发布时间。

#### 3. 涉政 / 涉地图内容

公开内容不得包含：

- 任何 AI 手绘的国界、海岸线、行政区划
- 台湾、海南岛、南海诸岛轮廓错绘/漏绘
- 政治符号、旗帜、标语

涉及位置用文字描述（"位于上海黄浦区"），不用图形。

#### 4. 标题必须说明内容（2026-09-10 修订）

标题要让读者一眼看出"这篇讲什么"，禁止"流水号 + 日期"式的无信息命名。

- ❌ 反例：`第5期`、`0906_1`、`活动预告`、单纯的 `X月X日开幕`（只有时间、没有内容）
- ✅ 正例：`外滩大会收官日看点与入场方式`、`上海工博会10月开幕 观展要实名预登记`、`广州具身智能展 面向专业观众`
- 保留要素：主体（哪场活动）+ 看点或门槛（讲什么、普通人能不能进）
- 仍受标题 ≤20 字硬限、正文 ≤1000 字硬限

#### 5. 参与方式必须写明（2026-09-10 修订）

写活动 / 展会 / 论坛类内容，**必须**交代普通读者能不能去、怎么去，不能只写"欢迎参加""可前往"这类含糊话。

按实际情况写全（确实无门槛就直说"无需预约、直接入场"）：

- 是否仅限邀约、是否仅对专业观众开放（B2B 专业展须明确"非专业/受邀人士不建议前往"）
- 是否需实名登记 / 预登记 / 审核，审核不通过是否无法入场
- 报名或预登记截止时间（不同渠道口径不一致时并列写出，并注明以官方为准）
- 入场凭证：身份证原件 / 电子票 / 二维码，是否需现场换证
- 名额与票数限制（限额报名、限购张数、最后一天提前截止入场）

理由：读者按文前往却进不去，是比写错时间更严重的误导。

#### 6. 来源标注格式

正文末尾用以下模板（可省其一）：

```
—
信息来源：XX 官网 / XX 媒体，YYYY-MM-DD
数据时间：YYYY-MM-DD
```

中文媒体用全名（如"上海发布"、"中新社"），不要写"中新网"。

## 验收清单（每篇发布前）

- [ ] 每个量化数据是否双源核实？
- [ ] 是否含价值判断 / 评价性形容词？
- [ ] 标题是否含判断词（却、但、竟等）？
- [ ] 是否含战略 / 政策性建议？
- [ ] 应急事件是否避免了伪造实拍？
- [ ] 地图类内容是否避开？
- [ ] 标题是否说明了"讲什么"，而不是只有流水号/日期？
- [ ] 活动类内容是否写清了参与方式（邀约 / 报名 / 审核 / 截止时间）？
- [ ] 来源是否标注？
