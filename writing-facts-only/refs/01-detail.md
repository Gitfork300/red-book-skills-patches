## 二、话题标签位置事故（2026-09-15，最高优先级）

**反例（0915 批次 30 篇全踩）**：

```
…正文段落…
#云栖大会 #云栖小镇 #人工智能 #AgenticAI
来源：2026云栖大会官方公告…      ← 标签后还有一行
```

结果：已发笔记 `tagList` 实测为 `[]`——只是纯文本，不是话题实体，不带话题流量。

**原因**：`_extract_topic_tags_from_last_line()` 只解析最后一个非空行，且要求该行每个 token 都形如 `#xxx`。标签行后跟着「来源」行 → 整行不匹配 → 话题选择静默整批跳过。

**正例（来源行提到标签行之前）**：

```
…正文段落…
来源：2026云栖大会官方公告…
#云栖大会 #云栖小镇 #人工智能 #AgenticAI      ← 最后一行
```

**验证（离线，不需要真发）**：`xhs_publish/publish/_verify_topic_tags.py`（官方提取函数逐篇校验，33/33 才准发）。
**零副作用实测**：`xhs_publish/publish/_probe_topic_entity.py a1`（只填表不提交，输出 topic id 即成功）。

已发笔记 `tagList` 为空是既成事实，网页端编辑能力有限，逐一补挂成本高且可能触发二次审核 → **新稿用新格式，旧稿不返工**（除非仍是流量主力）。

## 三、篇幅换算（为什么定这个数）

- 正文一屏 ≈ 18–20 行 × 18–20 字 ≈ 330–400 字；**1.5 屏 ≈ 500–600 字**。
- 核心正文 200–600 字 ≈ 0.5–1.5 屏；顶到 600 + 评级块约 155 字 ≈ 755 字 ≈ 2 屏，已到极限。
- 实测（2026-09-14 近 3 天 139 篇）：88% 全篇在 500 字内、中位约 374 字；评级块固定占 71–185 字（中位 155）。
