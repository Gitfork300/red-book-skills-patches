# writing-facts-only / refs — 评级块、话题标签与篇幅细节

## 事实汇总与分页去重

引用接口或简报中的总量前，确认分页参数确实返回不同记录；有重叠或接口重复返回时，按稳定唯一键（例如预警标题 + 发布时间）去重后再统计。不能将重复页逐页累加，也不能把请求页数当作数据覆盖完整的证据。

## 一、评级块格式（硬要求）

**所有展会/活动类稿件，正文末尾必带评级块**，固定「综合星级 + 四维 + 来源」：

> ⚠️ 首行「综合」的星级写在**汉字之后**：`综合 ★★★★☆`，**不是** `★★★★☆ 综合`（用户 2026-09-14 口径「汉字后标记打分，是『综合☆』不是『☆综合』」）。四维同理，汉字在前星级在后。

```
—
综合 ★★★★☆
参与难度 ★★☆☆☆ 个人免费（免费注册，需线上登记）
适合人群 个人 · 商务 · 开发者
专业性   ★★★★★ 技术向（芯片→云基础设施→模型→Agent 全链路）
活动规模 ★★★★★ 行业峰会（3大主论坛 / 140余场分论坛 / 超5万㎡ / 1000+企业）
来源：百度百科2026云栖大会词条、雪球、阿里云云栖号官方微博
```

> 首行「综合」不能省（发布链预检 `RATING_FIELDS` 已含，缺失即 SKIP）。
> ⚠️ 生成器/模板必须内置这一行：`_gen_*.py` 若漏写「综合」→ 整批集体缺行，单看一篇发现不了。新增/改生成器后必须核验输出首行，换模板后整批重跑。

**星级口径**（打星落在事实依据上，括号简述是依据，不许空、不许写评价）：

| 维度 | ★ | ★★ | ★★★ | ★★★★ | ★★★★★ |
|---|---|---|---|---|---|
| 参与难度 | 免预约·直接入场 | 个人免费（需登记/预约） | 个人收费 | 团体报名 | 商务/邀请制 |
| 专业性 | 大众科普 | 兴趣入门 | 行业通用 | 专业进阶 | 技术深水 |
| 活动规模 | 小型沙龙 | 市级活动 | 省级展会 | 全国展会 | 行业峰会/国际级 |

- 适合人群不打星，用标签列举（个人/家庭/学生/开发者/商务/专业观众）。
- 综合星级是对四项的汇总，紧邻正文能找到事实支撑。
- 星级属结构化元数据，不算"价值判断"，但括号简述必须是事实（规模/门槛/人数/场次），不许"值得去/干货多/阵容强"。

## 二、话题标签位置事故（2026-09-15，最高优先级）

**反例（0915 批次 30 篇全踩）**：

```
综合 ★★★★☆
…评级块…
#云栖大会 #云栖小镇 #人工智能 #AgenticAI
来源：2026云栖大会官方公告…      ← 标签后还有一行
```

结果：已发笔记 `tagList` 实测为 `[]`——只是纯文本，不是话题实体，不带话题流量。

**原因**：`_extract_topic_tags_from_last_line()` 只解析最后一个非空行，且要求该行每个 token 都形如 `#xxx`。标签行后跟着「来源」行 → 整行不匹配 → 话题选择静默整批跳过。

**正例（来源行提到标签行之前）**：

```
综合 ★★★★☆
…评级块…
来源：2026云栖大会官方公告…
#云栖大会 #云栖小镇 #人工智能 #AgenticAI      ← 最后一行
```

**验证（离线，不需要真发）**：`xhs_publish/publish/_verify_topic_tags.py`（官方提取函数逐篇校验，33/33 才准发）。
**零副作用实测**：`xhs_publish/publish/_probe_topic_entity.py a1`（只填表不提交，输出 topic id 即成功）。

已发笔记 `tagList` 为空是既成事实，网页端编辑能力有限，逐一补挂成本高且可能触发二次审核 → **新稿用新格式，旧稿不返工**（除非仍是流量主力）。

## 三、篇幅换算（为什么定这个数）

- 正文一屏 ≈ 18–20 行 × 18–20 字 ≈ 330–400 字；**1.5 屏 ≈ 500–600 字**。
- 核心正文 200–600 字 ≈ 0.5–1.5 屏；顶到 600 + 评级块约 155 字 ≈ 755 字 ≈ 2 屏，已到极限。
- 实测（2026-09-14 近 3 天 139 篇）：88% 全篇在 500 字内、中位约 374 字；评级块固定占 71–185 字（中位 155）。

## 四、验收清单（每篇发布前）

- [ ] 每个量化数据双源核实？无价值判断/评价性形容词/判断词/建议？
- [ ] 应急事件避免伪造实拍？地图类避开？
- [ ] 标题说明"讲什么"？活动类写清参与方式？来源标注？
- [ ] 展会/活动类带评级块，首行 `综合 ★…`，括号简述是事实不是评价？
- [ ] 核心正文（末个 `—` 前）200–600 字？全篇 <1000 字？（改一个字就重测）
- [ ] 分段适配扫读（一段一信息点、段 ≤3 行、首段 ≤2 行、段间空行、无文字墙）？
- [ ] 带 3–5 个 `#话题标签`（具体名词、正文事实、**最后一行**、`#` 后无空格）？每个标签验过热度、冷门已剔除？
