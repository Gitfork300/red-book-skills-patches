# organizer-qualification-guard（主办资质闸门）

> **执行边界**：本 patch 只判断主办方资质和活动含金量；时效、地域、用词与总预检由其他 patch 负责。

> 来源：2026-09-13 用户复盘「这一轮活动/展会 有很多私人机构的」——已发布的展会类里混入了
> 私人机构、付费小班、无名私企、小型沙龙/对接会。用户定下硬标准：
>
> **展会 / 活动 必须是「事业单位 / 行业龙头 / 行业协会」牵头的中大型活动，且正文要体现含金量。**
> 不接受：私人机构、付费小班、无名私企、小型沙龙 / 对接会。

> **收费不是原罪，主办方性质才是**（2026-09-14 用户澄清原话）：
> 「收费理解错了，我说的是私人活动存在收费，所以不发。
>  如果是政府部门或者行业峰会，还是可以发的。要注明是谁免费，谁收费，谁邀约。」
>
> → 政府 / 事业单位 / 高校 / 协会 / 行业龙头 / 会议品牌主办的活动，**有收费也可以发**，
>   但正文必须写清「**谁免费 / 谁收费 / 谁邀约**」；识别不到公共属性主办的收费活动 → 硬拒。

## 一、为什么单独成一道闸门

原有的 `timeliness-window` 只管「地域 / 时效 / 资格（是否公开可参与）」，**不查主办是谁**。
结果一批「能去、在 7 天内、但其实是私企办的小活动」照样发了出去。这道闸门补的就是
「**主办资质**」这一维，是发布前总检查（publish-preflight-guard）的可自动化条目之一。

## 二、判据与退出码

脚本：`helpers/check_organizer.py`

```
python helpers/check_organizer.py --title "..." --file content.txt
python helpers/check_organizer.py --title "..." --content "..."
```

退出码：

| 码 | 含义 | 发布前处理 |
|---|---|---|
| `0` | 通过：识别到合规主办方 + 正文有含金量信号 | 放行 |
| `1` | **硬拒**：命中培训/卖课类名词（组 A）、命中私人机构黑名单、**面向个人付费 ≥99 元且非年度/届次举办（规则 D，无论主办是谁）**、「主办/承办/由…主办」语境下的主办实体不含任何事业单位/龙头/协会字样，或**收费活动识别不到公共属性主办** | **阻断，不得发布** |
| `2` | **复核**：活动类但全文找不到明确主办方；**收费活动已识别公共属性主办、但正文没写清「谁免费」**；或**招聘类活动没有任何科技产业链定位** | 列出待人工确认，不自动阻断 |

只管「活动 / 展会 / 论坛」类内容（识别到活动名词才判）；研究 / 案例 / 科普资讯类
（无活动名词）**直接跳过（exit 0）**，由 `safe-wording-guard` 的站外导流闸门接管。

### 合规主办方判定（命中任一即通过主办方这一关）
- **品牌活动名**（标题/正文出现即合规）：世界人工智能大会、WAIC、智博会、数博会、外滩大会、
  浦江论坛、全联接大会、云栖大会、张江药谷、中国工业AI大会 等国际/国家级会议品牌。
- **主办语境下的实体含合规字样**：抽取「主办方 / 承办方 / 由 … 主办 / 组委会」之后 2~20 字，
  该实体需含以下任一：
  - 事业单位/高校：中科院、清华、北大、复旦、浙大、研究院、公立、科协、管委会、高新区…
  - 政府/街道/社区（须出现在主办语境后）：政府、街道、社区、少年宫、图书馆、博物馆…
  - 行业协会/学会：协会、学会、商会、CCF、IEEE、ACM…
  - 行业龙头/国央企白名单：华为、腾讯、阿里、字节、百度、京东、大疆、中国移动、之江实验室…
- **私人机构黑名单**（确证私企，直接硬拒，可扩写）：赤道象限、预策科技、Monad、宇树海康参访。

### 含金量信号
正文需出现以下任一：主办/承办/协办、院士/专家/学者/教授、国家级/省级/国际/全球、万人/千人参会、
参展企业、展览面积、论坛/峰会/主旨演讲、发布/签约/议题/分论坛、白皮书/报告/榜单/颁奖/竞赛/开源/生态。
合规主办方已识别、但**完全缺失含金量信号** → exit 2（复核），建议人工补强正文。

### 硬拒关键词 A：培训 / 卖课 / 私享性质（命中即 exit 1，**无论主办是谁**）

报名费 / 培训费 / 课程费 / 学费 / 收款码 / 私董会 / 内训 / 1对1辅导 / 研修班 / 特训营 /
总裁班 / 私享会 / 小班课 / 游学 / 考察团 / 训练营 / 高端局

（这类词指向卖课、内训、封闭小圈子，即便挂在某机构名下也不属于可发布的公开活动。）

### 收费判定 B：看主办方性质（2026-09-14 新口径）

命中下列**收费形式**（或正文出现非零价格 `169元` / `¥199` / `$99`）时，不直接拒绝，按主办方分流：

收费 / 票价 / 门票¥ / 早鸟价 / 会务费 / 缴费 / 付费参与 / 付费报名 / 展位费 / 招商 / 赞助席位 / 商业合作

| 主办方 | 判定 | 处理 |
|---|---|---|
| 政府 / 事业单位 / 高校 / 协会 / 行业龙头 / 会议品牌 | **可发** | 正文须写清**谁免费**；未写 → exit 2 复核。另提示：确认**谁收费、谁邀约**是否写明 |
| 识别不到上述任一公共属性 | **硬拒 exit 1** | 按「私人活动收费不发」处理 |

「谁免费 / 谁收费 / 谁邀约」三段式是**写稿要求**，不是可选修饰。
例（合规写法）：`企业展位收费 1000 元/场；个人求职者携带简历免费入场；邀约由主办方定向发出。`
`不收费 / 免费` 等否定语境不会被误判为收费（正则带否定环视）。

### 题材限定 C：招聘类只发科技产业链（2026-09-14 用户口径）

> 招聘会继续发，且**优先 AI / 科技产业链** —— 普通综合招聘会不发。

命中招聘类名词（招聘会 / 双选会 / 人才交流 / 校招 / 宣讲会 / 人才招聘 / 求职者）时，
正文**必须**出现至少一个科技产业链定位词，否则 exit 2 复核（实际不发布）：

人工智能 / AI / 半导体 / 集成电路 / 芯片 / 机器人 / 具身智能 / 智能制造 / 工业智控 /
自动化 / 新能源 / 新材料 / 生物医药 / 数字经济 / 软件 / 互联网 / 电子信息 / 智能网联 /
算力 / 大模型 / 低空经济 / 量子 / 通信 / 光电 / 智能终端 / 智能建造 / 跨境电商 / 大数据 / 科技

- 合规例：`上海AI产业链招聘会，覆盖人工智能、半导体、集成电路方向`
- 拦截例：`某区秋季综合招聘会，涵盖餐饮、零售、家政、保安岗位` → exit 2

**同时，招聘类也要带「参与难度 / 适合人群 / 专业性 / 活动规模 / 来源」底部评级块**
（见 `writing-facts-only` v1.2.0），与其他活动类稿件格式一致。

### 屏蔽规则 D：个人付费 ≥99 且非年度举办 → 硬拒（2026-09-14 用户口径）

> 用户原话：私人机构不好过滤。要求个人付费 99 以上的且非年度形式举办的活动，都屏蔽掉。

私人机构黑名单永远补不全，改用**「价格 + 频次」**作代理指标：一次性（非常设）活动还向个人收高价，
多数是私人机构办的营利场 —— **无论主办方是谁，一律 exit 1**。

判定分三步（脚本内 `personal_pay_hits()` + `ANNUAL_RE`）：

1. **抓价格**：`123元` / `¥123` / `￥123` / `$123`，取数值 ≥ **99（含 99）**
2. **判是否面向个人**（看价格前后 30 字上下文）：
   - 命中 `原价 / 价值 / 赠送 / 礼包 / 奖品 / 减免` → 是赠品或锚定价，**跳过**
   - 命中 `企业 / 展位 / 展商 / 团体 / 赞助 / 招商 / B端 / 商家 / 厂商` → B 端收费，**跳过**
   - 其余（含无任何标记的价格）→ **保守视为面向个人**
3. **判是否年度/届次形式举办**：
   - 命中 `第N届` / `年度` / `annual` / `每年` / `常年` / `一年一届` / `一年一度` / `第N年`
     → **不因价格屏蔽**，仅打印提示，继续走主办方与「谁免费」校验
   - 未命中 → **exit 1 硬拒**，并提示"若确为年度常设活动，请在正文写明届次后重跑"

| 例子 | 结果 |
|---|---|
| 某机构一次性沙龙，个人 199 元 | **exit 1 硬拒** |
| 单人票 99 元（边界） | **exit 1 硬拒** |
| 单人票 98 元 | 不触发本规则，走原收费分流 |
| 第 12 届年度峰会，观众票 500 元、学生免费 | **放行**（仅提示） |
| 招聘会"企业展位 1000 元每场；个人免费入场" | **放行**（B 端词命中，不算个人付费） |
| 现场赠送价值 199 元礼包 | **放行**（赠品） |
| 正文只写"380 元"无任何标记 | **exit 1 硬拒**（保守按个人处理） |

⚠️ **写稿影响**：确为年度常设的活动，正文**必须写出届次**（"第 12 届""年度峰会"），
否则会被本规则屏蔽。届次是事实，写出来同时满足「只陈述事实」要求。

## 三、接入发布前总检查

在 `publish-preflight-guard/helpers/batch_preflight.py` 中作为第 **16** 项自动运行：

```python
ORG = os.path.join(PATCHES_ROOT, "organizer-qualification-guard", "helpers", "check_organizer.py")
# 循环内，每篇稿件：
rc, out = run([PY, ORG, "--title", title, "--file", cp])
# rc==1 → fails.append((key, 16, "主办资质")) 阻断；rc==2 → 仅打印警告
```

退出码约定：`batch_preflight.py` 把 exit 1 计为未通过（阻断发布），exit 2 仅作人工复核提示。

## 四、已知边界（务必人工兜底）

1. **只认「主办/承办/由…主办」语境里的主办实体**。正文若完全不写谁主办（仅写「免费开放」），
   闸门给 exit 2 复核——这类可能正是无名私企，需人工看正文/来源定夺。
2. **私人机构黑名单是种子列表**，遇到新的确证私企（如某次出现的「赤道象限」）应补进
   `PRIVATE_ORG` 常量，逐步降低对人眼的依赖。
3. 不能替代「正文写清参与方式 / 含金量」等人工判据（见 publish-preflight-guard 第 5/6/7/12 项）。
4. 与电话闸门（`safe-wording-guard` 的 PHONE_RE）正交：某活动即便主办合规，若正文带电话仍会被电话闸门挡下。
