2. **时效**：开幕/报名日 ∈ **[D, D+7]**（专题 15d），免费登记不豁免。→`02`
3. **间隔**：**6–14min 随机**；起算=verify 通过；`reserve` 原子、`--max-block`≥840；工作区 `.state/publish/.guard.lock` 常驻禁删。→`03`
3b. **时段闸门**：**23:45–00:15 全组禁发**；专题解禁后 00:15 全组同权。→`03`
3c. **🔴 06:00 硬收口**：全链含 A/B/C 须 06:00 前发完；起跑由 `_deadline_guard.py plan` 反推（14.5min/篇，留 30min 缓冲）。→`03`

4. **内容**：只陈述事实不加评论；地域限制只对 E/F 生效；**正文禁一切联系方式/推广信息**（电话/邮箱/QQ/微信号/网址裸域名，含来源行）——`check_wording.py` P0 覆盖。→`04`
5. **字数**：正文 450–600、全篇 <1000；标题 15–25 字符（**字宽**≤20），封面文案 10–15 字。→`04`
6. **打星评级**块已废除：只留 `来源` 行 + 底部 `#话题` 末行。→`04`
6b. **非模板化**：同批首段禁复制；像填空模板即违规；段首禁数字、禁串讲套话。→`04`
7. **配图**：E/F 展会组官方图 ≥80%（无台账不发）；字卡 ≤20%；**无人物**/地图；**任何图禁二维码**——必跑 `check_qr.py`（exit1 禁发 / exit2 须目检裁决 + 白名单登记 / exit3 修复后重跑）。→`05`

## 时段与成本（token 口径）

> **高峰限制的是「token 消耗量」，不是「能不能发布」。**

- 高峰原价：周一至周五 09:00–12:00、14:00–18:00。其余时段与周末全天 5 折。
- **高峰不额外限制发布**：仍须遵守 23:45–00:15 禁发及 06:00/08:00 收口规则。
- **进度/流程检索不受限制**：查表、读日志、`verify`、看自动化状态、巡检判活等轻量动作高峰随时做。
- **只有重 token 活排非高峰**：写稿、起链、批量排名计算、大范围复盘分析 → 12:00–14:00、18:00 后或周末再跑。
- 不空转：等确认 >5 分钟即按默认值继续；轮询用长间隔，少复读文件。
