# 02 · 时效窗口与可发布资格

> read_when: 要判断某个展会/活动/招聘会能不能发时
> 本文件是 `MEMORY.md` 第 2 节的展开。**结论以主文件为准**。

## 核心口径（2026-09-14 收紧）

> 展会活动必须近 7 日开始入场，或近 7 天内开始/截止报名。
> **「免费登记/开放登记」只是主题提醒，不是豁免条件。**

## 合法入口只有两类

1. 开幕日 ∈ [D, D+7]
2. 报名开始日或截止日 ∈ [D, D+7]

**D+7 当天算窗内。**

## 专题系列

- **专题系列预热连载 = 15 天窗口**（`--category series`，`timeliness-window` v1.6.0）
- ⚠️ 延窗 ≠ 新增入口，三类入口一个没多
- **但专题的「生命长度」另有硬上限**（2026-10-21 用户裁定）：**同一专题连发 3-5 天换下一个，最长 ≤7 天**。
  15 天是「什么时候能开始发这个专题」，7 天是「这个专题最多能连发几天」——两件事，不冲突。
  会期长于 7 天的会，7 天到点必须切走，**不以「还没闭幕」续命**（`topics/03` 专题轮换周期节）。

## 地域闸门：只对 E/F 生效（2026-10-21 16:3x 用户裁定）

- **A / B / C 三个专题组一律豁免地域判定**（选题不限地域）。
- **E 组展会·江浙沪** 举办地必须属江浙沪；**F 组展会·珠三角港澳** 举办地必须属珠三角 + 中国香港/中国澳门。
- 判定：`xhs_publish/_geo_scope.py --date <MMDD> --strict`（越界 exit 1）。
- 上游 `timeliness-window/helpers/geo_check.py`（通用口径「会展只发江浙沪/珠三角」）**未改**，
  项目层按组覆盖（B-094）——不影响其他项目使用该 skill。

## 近期热点源（2026-10-21 用户裁定）

- 专题立项除时效/评分外，还须过**热点线**：题材须有**近 3–5 天**的公开热度信号
  （媒体报道 / 官方通稿 / 榜单 / 厂商发布，任一可查证）。
- 热度证据不足 → **不立项**（宁可不发，不做冷门长尾专题）。
- 判定走 `_topiclab.py` / `_TOPIC_RULE.md` 的热度口径（H ≥ 1.2 视为热）。

## 事故与教训

- ⚠️ 云栖 9/22（D+8）曾以「免费登记已开启」为由豁免并发出，被用户当场否掉
  → 已进 v1.4.0 复盘。**人工豁免不能用来绕过规则本身**

## 收费活动

- 禁的是**私人活动收费**
- 政府 / 事业单位 / 高校 / 协会 / 行业龙头 / 会议品牌主办的有收费也可发，
  但正文须写清**谁免费 / 谁收费 / 谁邀约**
- 卖课 / 内训 / 私享会（总裁班 / 研修班 / 小班课）**硬拒**
- 依据：`organizer-qualification-guard` v1.1.0

## 邀请制

- 邀请制可发：`--public-signup invited` → `ELIGIBLE_INVITE` rc=0（**仍须给 `--live`**）
- 无直播 + 邀请制 → 只写已公开成果与案例（**≥2 个独立来源**）
- **正文必须注明邀请制**

## 个人付费硬拒

- 🚫 个人付费 **≥99** 且非年度 / 届次 → 一律硬拒（v1.3.0）
- 抓价格 → 区分个人 / B端 / 赠品 → 有「第N届 / 年度」则豁免
- **年度常设活动正文必须写出届次**

## 招聘会

- 只发有科技产业链定位的：AI / 半导体 / 集成电路 / 机器人 / 具身智能 / 智能制造 /
  生物医药 / 新能源 / 算力 / 大模型
- 普通综合招聘会不发（v1.2.0，未命中 rc=2）
