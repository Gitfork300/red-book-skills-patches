# cover-image-rules

> **范围**：只管公开发布内容的封面；不管正文、评论和私信。
> **执行顺序**：先判图源和红线，再做构图，最后跑来源台账校验。

## 硬规则

1. 展会/活动类每批官方宣传图占比必须 **≥80%**；不足、无台账或图源不明，不得排队。
2. 禁止可识别人物、人物特写、宣传大使、二维码、条形码、票券、地图/边界、旗帜/国徽、可读文字和数字。
   **二维码是独立硬闸门、且适用「任何图」**（官方图 / 官方海报 / AI 生图 / 字卡一律适用）——
   见下节「二维码硬闸门」，必须跑 `check_qr.py`，不能只靠目检。
3. 活动/展会/场馆/设备类优先真实感照片；官方图优先，拿不到时按“真实感生图 → 摄影质感字卡 → 自然风光 → 抽象示意图”退让。
4. AI 生成图必须传 `--content-declaration`；官方实拍不传。混用按含 AI 处理。
5. 台风、暴雨、地震、事故等紧急事件不得生成伪造实拍；使用一眼可识别的矢量示意图，并注明“封面为 AI 生成示意图，不代表真实云图或现场情况”。
6. 真实感或官方图仍需人工检查年份、人物、地图、文字和主题匹配；调用成功不等于文件已落盘，必须核对数量和文件名。
7. **不得拉伸源图**；裁切须保留主体与关键信息，横幅/官方 KV 按完整缩放加背景延伸适配画布。
8. 每段可见标题/角标只由一个公共绘制入口负责；单图函数不得再次绘制相同文案。生成后逐张检查有无重影、变形、遮挡和素材错配。
9. **封面唯一性（2026-10-14 新增，血泪教训）**：**同一批内、以及同一专题跨天，禁止复用同一张源图**。
   - 判据用感知哈希：任意两张封面 ahash 距离必须 **≥12**（只换封面文案、底图相同仍算重复）。
   - 「同一专题只有一张官方主视觉」**不是**复用理由：必须去找该专题的其它官方物料（承办场馆实景、议程主视觉、
     往届现场、KV 变体等），凑不够就退回 `真实感生图 → 摄影质感字卡 → 自然风光 → 抽象示意图`，**不得连续复用**。
   - 发布前跑（cwd = 稿件目录，脚本用绝对路径）：
     ```bash
     python <patch>/cover-image-rules/helpers/check_cover_unique.py --date <MMDD>
     ```
     退出码 `0` 通过，`1` 存在近重复（**禁止排队发布，必须换图重做**），`2` 依赖或输入错误（必须修复并重跑）。此门禁与第 1 条官方图占比校验并列，两者都要过。

## 二维码硬闸门（2026-10-23 用户拍板，B-101）

> 用户原话：「**任何图 都不应该包含二维码**」——不限官方图、AI 生成图、字卡。

事故：`f1023_02`（中德智能机器人论坛）封面直接用学会官网海报，海报主体是**微信二维码**，发布后被用户发现。
二维码属平台**站外导流高危元素**（比水印严重：水印裁边可解，二维码只能换图）。

**发布前必跑**（cwd = 稿件目录）：

```bash
python <patch>/cover-image-rules/helpers/check_qr.py --dir <稿件目录>
# 或指定文件：python <patch>/cover-image-rules/helpers/check_qr.py --file a_cover.png b_cover.png
```

- 退出码 `0` 通过 / `1` **确认含码**（禁发）/ `2` **疑似含码**（必须人工目检裁决）/ `3` **依赖缺失、空输入、白名单损坏或检测错误**（修复后重跑，不可视为通过）。
- 人工目检确认无码后登记白名单（**按文件 md5 绑定**，同名重生成后自动失效、需重新目检）：

```bash
python <patch>/cover-image-rules/helpers/check_qr.py --mark-ok a_cover.png --date 1023 --note "AI 生成图，无码"
```

白名单属于业务状态，默认保存在 `<workspace>/.state/covers/qr_whitelist.json`，不放入 Skill。
旧版 Skill 树内白名单会在首次读取时迁移；若新旧内容不一致，检查会停止并要求人工核对。

- 检测原理：灰度 → 等比缩放 → Otsu 二值化 → `detect()` 定位 → 裁剪放大 `detectAndDecode()` 确认。
  **不要用全分辨率 detect**——它会在无码海报上误报（实测 f01_p1 全分辨率命中、二值化后不命中）。
- AI 生成图的点阵/网格/电路纹理容易触发「疑似」，属正常；目检无码后登记白名单即可，不要为躲白名单而放弃检查。

## 官方图与构图

- 来源优先级：主办方/组委会官网、官方通稿、官方媒体、场馆/展区官方图。
- 官方图含人物时依次换图、裁切为非人物主体、改用地标/场馆示意图。
- 横版官方 KV 不得裁掉文字；完整缩放时用同图模糊延伸补底。普通视觉图可裁成 2:3 竖图。
- 右下角可加来源小字；官方图不加 AI 水印。

## 来源台账与校验

每批建立 `cover_sources_<批名>.json`，每张至少记录 `key`、`source`、`url`、`origin`、
`treatment`、`reason`。发布前运行：

```bash
python <patch>/cover-image-rules/helpers/check_cover_source.py --batch-dir <稿件目录>
```

退出码：`0` 通过；`2` 官方图比例不足；`3` 台账缺失或字段不全；`4` 封面文件缺失。
