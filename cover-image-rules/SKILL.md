# cover-image-rules

> **范围**：只管公开发布内容的封面；不管正文、评论和私信。
> **执行顺序**：先判图源和红线，再做构图，最后跑来源台账校验。

## 硬规则

1. 展会/活动类每批官方宣传图占比必须 **≥80%**；不足、无台账或图源不明，不得排队。
2. 禁止可识别人物、人物特写、宣传大使、二维码、条形码、票券、地图/边界、旗帜/国徽、可读文字和数字。
3. 活动/展会/场馆/设备类优先真实感照片；官方图优先，拿不到时按“真实感生图 → 摄影质感字卡 → 自然风光 → 抽象示意图”退让。
4. AI 生成图必须传 `--content-declaration`；官方实拍不传。混用按含 AI 处理。
5. 台风、暴雨、地震、事故等紧急事件不得生成伪造实拍；使用一眼可识别的矢量示意图，并注明“封面为 AI 生成示意图，不代表真实云图或现场情况”。
6. 真实感或官方图仍需人工检查年份、人物、地图、文字和主题匹配；调用成功不等于文件已落盘，必须核对数量和文件名。
7. **不得拉伸源图**；裁切须保留主体与关键信息，横幅/官方 KV 按完整缩放加背景延伸适配画布。
8. 每段可见标题/角标只由一个公共绘制入口负责；单图函数不得再次绘制相同文案。生成后逐张检查有无重影、变形、遮挡和素材错配。

## 官方图与构图

- 来源优先级：主办方/组委会官网、官方通稿、官方媒体、场馆/展区官方图。
- 官方图含人物时依次换图、裁切为非人物主体、改用地标/场馆示意图。
- 横版官方 KV 不得裁掉文字；完整缩放时用同图模糊延伸补底。普通视觉图可裁成 2:3 竖图。
- 右下角可加来源小字；官方图不加 AI 水印。

## 来源台账与校验

每批建立 `cover_sources_<批名>.json`，每张至少记录 `key`、`source`、`url`、`origin`、
`treatment`、`reason`。发布前运行：

```bash
python <patch>/cover-image-rules/helpers/check_cover_source.py --batch-dir <稿件目录>
```

退出码：`0` 通过；`2` 官方图比例不足；`3` 台账缺失或字段不全；`4` 封面文件缺失。
