# 封面操作细节

## 官方图获取

扫描官网 HTML 的 `src=`、CSS `url()`、`content=` 和 JSON 字符串，优先筛选宽至少
800、高至少 400 的候选；logo、图标和往届回顾图排除。下载时带官网域名的
`User-Agent` 与 `Referer`，大图超时可使用 CDN 缩放参数。

生成 contact sheet 后一次检查人物、年份、地图/平面图和文字密度。旧年份主 KV
不得配当前活动；清晰人形、人群合影和多栏文字图直接淘汰。

## 竖版适配

- 视觉图：裁 2:3 竖窗，目标尺寸 1024×1536。
- 含关键信息的官方 KV：完整缩放居中，上下用同图模糊、压暗延伸补底，禁止竖裁切文字。
- 每张图保存为 `<用途>_<序号>.png`，生成后核对数量、尺寸、时间和文件名。

## 生图与 PIL

提示词必须包含真实摄影质感，并显式禁止文字、数字、logo、二维码、人物、车辆和地图。
不得用 PIL 拼接戒指、手机、车、锁、医疗十字等图标集合；若必须程序化生成，使用
渐变、柔光、bokeh、压暗和显式行标题，避免逐行刷像素造成条纹。

并行生图时每个提示词开头要不同，避免文件名前缀碰撞导致后生成文件覆盖先生成文件。
生成后逐张核对，缺图必须补齐，不能把“调用成功”当作“文件存在”。

## 紧急事件

不用 AI 伪造现场照片、卫星云图或灾情截图，也不用含地图边界的官方气象图。
使用城市天际线、云层、雨丝等明确示意元素，并同时完成 AI 水印、发布命令声明和正文说明。
