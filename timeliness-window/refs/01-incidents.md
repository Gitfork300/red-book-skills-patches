# 时效与资格事故速查

| 现象 | 判据 | 处置 |
| --- | --- | --- |
| 远期活动因“已开放免费登记”被误放行 | 免费或可登记不改变硬日期窗口 | 只按当前日期窗口判定；规则未覆盖不等于可人工豁免 |
| 时效合格但目标读者不能参加 | 报名资格 / 直播可见性与时效是独立条件 | 发布前同时核验可参与资格；邀请制按现行要求标注 |
| 批次中出现地域不合规活动 | 组别决定地域规则，不能只按标题判断 | 选题阶段先核验地区；按当前组别应用地域门禁 |
| 文案写了未经确认的直播信息 | 只有计划而无确定平台和时间不构成已确认直播 | 仅写已核实信息；无法核实则不声称有直播 |
