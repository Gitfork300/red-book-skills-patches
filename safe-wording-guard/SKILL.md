# safe-wording-guard（小红书安全用词守卫）

> **体系：`publish`（发布体系）** —— 只管**已发布的笔记文案**（标题+正文+话题标签），**不管评论回复与私信**（属 `comment-reply-guard`）。
> 二者口径**刻意相反**：笔记正文**一律不出现网址/裸域名**（本 skill）；评论/私信问「怎么报名」时**必须给具体报名网址**。判定前先确认对象是「笔记」还是「回复」。见 `SYSTEMS.md` X1。

## 一、敏感词（出现即高危）

| 类别 | 敏感词 |
|---|---|
| 官方渠道点名 | 官方 H5、官方小程序、官方 App、官方公众号、官方报名、官方通道、官方入口 |
| 第三方平台点名 | 微信、公众号（直接点名）、支付宝小程序、抖音、B 站、知乎 |
| 链接/二维码 | 直接放 URL（即使是官网）、放二维码、"扫码"、"添加联系方式" |
| 拉新转化词 | 报名、预约、注册、下载、登录、扫码进群、加好友、领优惠、限时领取 |
| 自夸数据 | "报名已突破 X 万"、"售罄"、"全网销量第一"、"现象级刷屏" |

经验法则：任何可能被算法解读为"让用户离开小红书去另一个平台"的表达都要避开。

## 二、平台硬限制（最隐蔽）

| 项 | 上限 | 超限表现 |
|---|---|---|
| 标题 | **20 字（按字宽）** | ⚠️ 静默失败：不报错、发布按钮可点，但点了完全不发请求，只有编辑器 toast 一闪而过 |
| 正文 | 1000 字 | 提交时明确拒绝 |

**字宽口径**：汉字/全角符号计 1，英文/数字/半角符号每 2 个计 1（`hello`=3、`你好hello`=4）。旧脚本按 `len()` 逐字符计数会把含数字标题误判超限。
**为什么最危险**：不产生可捕获错误，发布脚本看到 `READY_TO_PUBLISH` 正常，点下去却什么都没发生，容易误判成"脚本坏了/被风控"。

> 1000 是平台硬限（提交红线），写作执行带更严：**核心正文（末个 `—` 前）450–600 字 + 全篇 <1000 字**（权威见 `writing-facts-only`，闸门见 `publish-preflight-guard` 第 9 项）。

## 二之二、专题系列标题不写序号（硬规则）

> 用户 2026-09-18 原话：「另外[专题] 后续不要写序号在主题中」。

| 项 | 口径 |
|---|---|
| 适用对象 | **标题（主题）**；正文不受此限 |
| 禁止写法 | `①②③…`、`（一）（二）…`、`系列①/系列1/系列一` 等任何序号 |
| 正确写法 | 直接写内容本体：❌「云栖系列① 5篇一次看全」→ ✅「云栖5万平展区 四大主题馆」 |

判定：标题命中序号模式即 **P0（必须改）**，`check_wording.py` 已内置（2026-09-18 起，仅查标题）。

## 三、安全替代说法（核心）

- 报名/入场：❌ 官方 H5 报名/扫码 → ✅ 看评论区置顶 / 留意官方账号近期推文 / 凭大会身份入场。
- 时间地点：❌ 贴链接 → ✅ 写"地点：上海市黄浦区… / 9月9日—12日"。
- 账号名：❌ 关注公众号「XX」→ ✅ 关注主办方账号。
- 想突出热门：❌ 报名突破 5 万/现象级 → ✅ 吸引了大量关注 / 报名反响热烈。
- 说免费：❌ 免费报名 / 0 元抢票 → ✅ 观众免费开放 / 对公众开放。
- **来源标注 ≠ 贴网址**：只写「机构名 + 项目名 + 论文编号」，不能出现域名。`arXiv 2608.23189` 纯编号安全；`github.com/xxx`、`xxx.ai` 裸域名同罪。

**组合判定（易漏）**：「报名/预约/注册 + 免费/限时」同现 → P1 告警。活动稿必须写参与方式，故把"免费"一侧换成「不收费 / 无需购票 / 可免 XX 元」，保留"登记/报名"。

## 四、预检脚本 `helpers/check_wording.py`

```bash
python helpers/check_wording.py --title "标题" --file path/to/content.txt
```

退出码：0 安全 / 1 命中 P0 / 2 命中 P1。⚠️ 传正文一律用 `--file`（`--content` 收的是文本本身，传路径只会检查路径字符串）。

**P0（必须改）**：标题字宽 >20；正文 >1000；直接放 URL（http/https）；站外域名（裸域名同罪）；"扫码/添加好友/加群"；"官方 H5/小程序/公众号/App/报名"；直接点名第三方平台（微信/支付宝小程序/抖音/B 站）；**电话号码**（手机/座机/400，含空格短横分隔，一律改「联系主办方官方账号」）。

**P1（建议改）**：报名/预约/注册/下载（单独风险不大，与免费/0元/限时组合时高危）；自夸数据（突破 X 万/刷屏/现象级/售罄）。
