# 文案事故速查

| 现象 | 判据 | 处置 |
| --- | --- | --- |
| 标题肉眼不长却触字数闸门 | 限制按字宽计算，不等于字符数 | 按当前脚本字宽复核并留余量，修后重跑 |
| “免费”与“报名 / 登记”组合触发风险 | 需判断是否命中当前组合规则，不以单个词判断 | 使用事实准确且符合当前词规的表达，再跑完整预检 |
| 来源标注被判为站外导流 | 裸域名与完整 URL 都可能被识别为链接 | 删除不必要的链接表达，复核来源事实并重跑预检 |
| 检查结果与实际稿件不符 | 传入内容文本而非文件，或脚本使用了错误输入参数 | 对真实稿件文件调用规定参数；确认检查对象与队列文件一致 |
